# 《鎖 -クサリ-》汉化工具集

Kusari Translation Toolkit —— 解包、脚本反汇编/汇编、文本提取注入、位图字体重绘、exe 内嵌文本修改。

## 游戏与引擎

| 项目 | 内容 |
|---|---|
| 游戏名 | 鎖 -クサリ-（Kusari） |
| 厂商 | Leaf |
| 发售 | 2005-09-22 |
| VNDB | <https://vndb.org/v181> |
| 引擎 | xlvns（脚本容器版本 `LF` / 76,70） |
| 封包 | **LAC PAK**（`LAC\0`，40 字节目录项，自定义 LZSS） |
| 脚本 | **SDT**（`L\0F\0` 头 + 256 dword 入口表 + 字节码） |
| 字体 | **FNT**（无文件头，8316 个 8bpp 方形字形，24px / 12px） |
| 文本编码 | CP932 / Shift-JIS，文本内嵌在指令操作数中 |
